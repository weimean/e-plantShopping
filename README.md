e-plantShopping is a React and Vite web application for browsing plants and managing a shopping cart in a clean, fast storefront experience.

## Project Overview

This repository, e-plantShopping, contains a small e-commerce style frontend focused on plant products.
The app lets users:

- View a list of plants
- Add and remove items in the cart
- Update cart quantities
- See cart totals through Redux state management

## Tech Stack

- React
- Vite
- Redux Toolkit
- React Redux

## Run Locally

1. Install dependencies:
	npm install
2. Start development server:
	npm run dev
3. Build for production:
	npm run build
4. Preview production build:
	npm run preview
